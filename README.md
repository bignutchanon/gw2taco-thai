# GW2 TacO ฉบับภาษาไทย (ไม่เป็นทางการ)

Unofficial Thai translation and bug-fix patch for [GW2 TacO](https://github.com/BoyC/GW2TacO) by BoyC. Not affiliated with or endorsed by BoyC or ArenaNet.

ไฟล์แพตช์ที่ผู้เล่นไทยทำเพิ่มบน GW2 TacO ของ BoyC ใช้ลงทับ TacO ตัวทางการ ไม่ใช่ของทางการ และ BoyC ไม่ได้เกี่ยวข้องกับฉบับนี้ ถ้าเจอปัญหาให้แจ้งที่ [Issues](../../issues) ของ repo นี้ อย่าไปแจ้ง BoyC

## มีอะไรใหม่

- เมนูและหน้าต่างทั้งหมดเป็นภาษาไทย (ใช้ฟอนต์ Leelawadee UI หรือ Tahoma ที่มากับ Windows)
- หน้าต่าง "ตั้งค่า GW2 TacO" รวมการตั้งค่าทุกอย่างไว้ที่เดียว แบ่งเป็นแท็บ
- เมนู TacO หน้าตาเหมือนหน้าตั้งค่า: เปิด/ปิดด้วยช่องติ๊ก
- ลากปุ่ม TacO ไปวางตรงไหนก็ได้ (เปิด "โหมดแก้ไขหน้าต่าง" ก่อน)
- กรองมาร์กเกอร์ได้เร็วขึ้น: แสดงทั้งหมด, ซ่อนทั้งหมด, แสดงเฉพาะหมวดนี้ และตั้งปุ่มลัดให้แต่ละหมวด
- ตัวจับเวลาแผนที่อัปเดตถึง Visions of Eternity
- แก้บัคหลายตัว เช่น วาง API key ด้วย Ctrl+V ได้ และตั้งปุ่มลัดเป็นปุ่ม numpad / F1-F12 ได้

รายการเต็มอยู่ในไฟล์ `README_TH.txt` ใน zip

## วิธีติดตั้ง

1. โหลด GW2 TacO ตัวทางการ (เวอร์ชัน 067) จาก [gw2taco.com](http://www.gw2taco.com) แล้วแตกไฟล์ไว้ในโฟลเดอร์ที่ต้องการ
2. ปิด TacO ถ้าเปิดอยู่
3. สำรองโฟลเดอร์ TacO ไว้ก่อน (copy ทั้งโฟลเดอร์ไปไว้ที่อื่น)
4. โหลด `GW2TacO_067.3705r-th2.zip` จากหน้า [Releases](../../releases/latest)
5. แตกไฟล์ zip ลงในโฟลเดอร์ TacO แล้วกดเขียนทับไฟล์เดิม
6. เปิด TacO แล้วคลิกปุ่ม TacO > TacO Settings... > แท็บ General > Language > Thai

ถอนการติดตั้ง: เอาโฟลเดอร์ที่สำรองไว้กลับมาแทน หรือแตก zip ตัวทางการทับ
